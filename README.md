## 열기

`index.html`을 브라우저로 열면 됩니다. CSS·JavaScript·학습 데이터가 모두 들어 있어 서버 설치 없이 사용할 수 있습니다. 출처 사이트를 열 때는 인터넷이 필요합니다.

## 사용할 수 있는 기능

- SK하이닉스·삼성전자·대한광통신 사례 21개와 해석, 확인 질문
- 확인된 원글의 맥락 요약과 개별 글 링크, 작성자·확인일·부분 확인 범위 표시
- 용어집 검색, 용어 설명, 사례에서 사용한 용어 필터, 용어집 인쇄
- 투자분석 탭: 차트 18개·기업 분석 18개·투자 대가의 관점 6개 수업과 종합 실습
- 가상 차트의 기본 예시·반례 비교, 이동평균 기간 조절, 계산값 표 보기
- 가상 기업의 주가·성장률·할인율을 조절하는 가치평가 실습, 수업별 인쇄
- 문장·용어 저장, 학습 완료 표시, 복습
- 국내 종목 이름·6자리 코드 추가, 해당 커뮤니티 열기, 직접 글과 해석 추가
- 글 해석하기: Mac의 ChatGPT 로그인 Codex로 본문을 짧게 분석하고 답변 스트리밍·중지·복사
- 개인 기록 JSON 백업 및 가져오기
- 자료 업데이트 안내, 직접 추가한 사례만 제안 JSON으로 내보내기, Codex 업데이트 요청문 복사

## 개인용 글 해석 기능

[글 해석하기](https://stat-thon.github.io/stock-language/#interpret)에서 본문을 붙여넣고 핵심 주장·용어·근거와 추정·확인 질문을 읽을 수 있습니다. API 키 대신 이 Mac의 Codex ChatGPT 로그인을 사용하며, Mac 연결 프로그램이 켜져 있어야 합니다. `Start Analysis.command`를 더블 클릭하거나 `npm run bridge`로 실행합니다. [연결·사용 안내](BRIDGE.md)를 참고하세요.

입력과 결과는 사이트에 자동 저장·공개하지 않습니다. URL은 출처 표시용이며 본문을 자동 수집하지 않습니다. 원격 휴대폰 연결은 포함하지 않으며 공개 Pages와 로컬 사본의 기존 개인 기록은 주소별로 구분됩니다.

## 자료 업데이트

사이트 하단의 **자료 업데이트**를 열면 다음 업데이트에 필요한 방법과 링크가 나옵니다. Codex에 새 글 확인·선별·해석·배포를 요청하거나, 직접 추가한 사례를 제안 JSON으로 내보내 검토 후 반영할 수 있습니다.

공개 자료가 저장소 `main`에 반영되면 GitHub Actions가 데이터 검증 → 단일 HTML 생성 → Pages 배포를 실행합니다. 커뮤니티 글을 자동으로 가져오는 기능은 아닙니다. [자세한 업데이트 안내](UPDATE.md)를 참고하세요.

개인 기록은 브라우저의 로컬 저장소에 보관합니다. 다른 브라우저나 기기로 옮기려면 ‘내 학습장’에서 백업을 내보내세요. 파일 위치를 바꾸면 브라우저에 따라 기존 기록이 보이지 않을 수 있습니다.

기존 localhost 미리보기에서 쓰던 기록도 백업 내보내기 후 Pages에서 가져오면 옮길 수 있습니다. 전체 개인 백업은 공개 저장소에 업로드하지 마세요.

## 자료의 범위

2026년 9월 12–18일 한국시간 기준, 공개 웹 화면을 Computer Use로 스크롤하며 읽고 수작업으로 선별했습니다. 전체 게시물을 전수 조사한 것은 아닙니다. 짧은 발췌의 표현·맞춤법은 유지했고, 학습 제목·해석·질문은 별도로 작성했습니다. 두 구절 사이의 생략은 `…`로 표시합니다.

2026-09-18 업데이트 후 16개 사례는 개별 글 주소로 연결됩니다. 나머지 5개는 종목 피드 링크이며, 카드에 한계를 표시합니다. 전체 공개 맥락 요약 12개와 공개된 부분만 확인한 요약 4개를 구분합니다. 기사 링크를 공유한 글의 전체 요약은 커뮤니티 본문에 한하며 연결 기사 전문의 확인을 뜻하지 않습니다. case-08·case-11은 같은 원글입니다. case-03은 공유 버튼에 링크 복사 불가 안내가 나타났습니다. 원문 전문을 재게시하지 않고 직접 쓴 요약과 짧은 인용을 구분합니다. 정확한 게시시각을 확보하지 못한 글은 최초 수집 당시 상대시간을 유지하고, 원문 재확인일은 별도로 표시합니다.

원문을 실제 화면에서 읽은 사실과 그 글의 주장이 정확하다는 것은 다릅니다. 글쓴이의 시세·실적·확률·배당 전망을 확인된 수치로 제시하지 않습니다. 용어집의 근거 링크는 개념 설명을 뒷받침하며 원문의 모든 주장을 검증하지 않습니다.

공식 Open API의 커뮤니티 조회 기능은 확인하지 못했고, 일반 공개 GET의 선행 조회는 403으로 응답했습니다. 커뮤니티 API를 통한 자동 수집·실시간 시세 연결은 없습니다. 별도의 개인용 글 해석 탭은 사용자가 붙여넣은 본문을 Mac의 Codex로 분석합니다. 추가 종목은 직접 출처를 열고 읽어 학습 기록을 추가하는 방식입니다.

## 편집과 재생성

`cases.json`은 사례, `glossary.json`은 용어집, `meta.json`은 수집 방법을 담습니다. `collection-notes.json`에는 수집 시 정리한 짧은 발췌와 맥락 메모가 있습니다. `analysis.json`은 투자분석 수업·가상 실습·근거 자료를 담습니다.

```sh
npm run build
npm test
```

빌드는 패키지 설치 없이 실행할 수 있습니다. 브라우저 테스트 준비는 [업데이트 안내](UPDATE.md)를 참고하세요. `index.template.html`, `tokens.css`, `styles.css`, `app.js`, `analysis.css`, `analysis-math.js`, `analysis-charts.js`, `analysis.js`, `interpret.js`, `interpret.css`와 데이터를 묶어 `index.html`을 다시 만듭니다. 기존 작업 폴더의 다른 앱과는 독립되어 있습니다.
